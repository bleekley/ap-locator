# Security and sensitive data

Never post credentials, `.env`, raw SSH sessions, customer inventories, or generated
reports in public issues. The tool's local outputs contain network and site data;
store and share them according to your organization's requirements.

Report a suspected vulnerability through GitHub's private vulnerability reporting
feature when available. If it is unavailable, open an issue requesting a private
contact channel without including exploit details or sensitive data.

AP Locator is a community utility with no guaranteed support response time.
Use scoped accounts and approved management access. Legacy SSH compatibility
requirements should be evaluated within your own environment. The CSV checksum
checks file consistency; it is not a security signature.
